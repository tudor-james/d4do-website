Secure by Design

How Cosmogony separates user devices, orchestration, isolated sandboxes, and your AI models to keep your environment safe

Why Traditional AI Coding Tools Create Risk

Most AI tools run generated code directly on a developer's laptop, inside a shared build pipeline, or in an unmanaged vendor cloud:

Running on developer laptops

When AI runs commands on a personal workstation, it can reach local files, saved credentials, cloud keys, and active browser sessions.

Running inside deployment pipelines

Giving AI direct access to production pipelines exposes deployment secrets and broad permissions meant only for locked-down releases.

Locked into a single vendor cloud

When you cannot bring your own approved AI endpoints or control where workspaces run, you lose governance over your code and data.

High-Level C4 Architecture

Hover any component for details

Cosmogony is structured around a clean separation of concerns across four key layers:

CLI, Web UI & VS Code Plugin

Your team works through lightweight client interfaces—the 3-column Terminal CLI, the Web UI dashboard, or the VS Code Plugin. Nothing the AI generates ever executes on your personal device.

Cosmogony Core

Runs inside your controlled environment to coordinate shared sessions, manage workflows, enforce human review checkpoints, and track cost and team governance.

Secure Sandboxes

Every session executes in its own isolated, single-use sandbox container. Changes are built, tested, and pushed to a dedicated feature branch—never touching your main branch directly.

Bring-Your-Own LLMs

Connect the AI providers your organisation already approves—including OpenAI, Anthropic, Google Gemini, Vertex AI, AWS Bedrock, or private local models—with zero vendor lock-in.

Built-In Security Threat Modeling

Security in Cosmogony isn't just about how the platform is architected—it's also a built-in workflow your team can run on any project. Teams can launch a dedicated Security Threat Modeling session to evaluate application boundaries, identify potential risks, and produce actionable security recommendations before code ships.
