Secure by Design

How Cosmogony protects your code, your credentials, and your devices—while helping your team model threats proactively

Why Traditional AI Coding Tools Create Risk

Most AI tools run generated code directly on a developer's laptop, inside a shared build pipeline, or in an external vendor cloud. That creates three major risks:

Running on developer laptops

When AI runs commands on a personal workstation, it can reach local files, saved passwords, cloud keys, and active browser sessions.

Running inside deployment pipelines

Giving AI direct access to production pipelines exposes deployment secrets and broad permissions that were meant for locked-down automation.

Sending code outside your perimeter

When your source code and data are processed in an unmanaged third-party environment, you lose visibility and control over your security boundary.

Our approach: Cosmogony never runs AI-generated code on your personal devices and never gives AI direct access to your production environment. Every session works inside a clean, isolated workspace governed by strict platform rules.

Isolated Workspaces Inside Your Environment

Hover any component for details

Every Cosmogony session runs inside a fresh, single-use workspace provisioned within your hosted environment. Whether your team connects from the Web dashboard, VS Code, Terminal CLI, or the Android mobile app, their device is purely a control and review interface—never an execution environment.

Your environment, your rules

Deploy Cosmogony in your own cloud or on-premises environment so your data governance, privacy policies, and security controls apply automatically.

One clean workspace per session

Each session gets a brand-new, isolated workspace that is automatically removed when the session ends—no leftover state and no cross-project exposure.

Secrets stay out of reach

Organisation secrets, database passwords, and AI provider keys are managed securely by the platform and are never exposed inside the session workspace.

Safe across Web, IDE, CLI & Mobile

Nothing the AI builds or tests runs on your laptop or phone. Every client app is a lightweight, secure interface for chatting and approving checkpoints.

Protected main branches

AI teammates work exclusively on dedicated session feature branches (`cosmogony/<id>`). They can never push directly to your `main` or production branch.

Ready for private & air-gapped networks

Run entirely within private networks using internal package mirrors and self-hosted or VPC-hosted AI models when regulations require zero public internet traffic.

Built-In Security Threat Modeling

Security in Cosmogony isn't just about how the platform runs—it's also a built-in workflow your team can run on any project. Selecting the Security Threat Modeling workflow guides specialist AI teammates to evaluate your application boundaries, identify potential attack surfaces and risks, and produce actionable security recommendations that your team can review and turn directly into delivery tasks.

Admin-Controlled Tools & Access Governance

Organisation administrators have complete control over who can access the workspace and which tools AI teammates are allowed to use:

  • GitHub Sign-In & Invitation Approvals: Authenticate users with GitHub and control membership across organisations, teams, and projects.
  • Approved Tool Catalog: AI teammates can only use tools and integrations that an administrator has explicitly enabled for the organisation.
  • Locked-Down Network Access: Session workspaces can only reach your project repository and approved package sources—blocking unauthorized external connections by default.
  • Complete Activity & Audit History: Every stage deliverable, checkpoint decision, tool action, and branch commit is recorded with clear user and session attribution.
